# WorkBuddy 每日积分自动领取（多账号）

基于 WorkBuddy 客户端登录态，自动完成每日签到与成长中心"猫猫旅行"任务，多账号独立凭证，纯 Python 标准库实现（Web 界面亦零第三方依赖）。

> **仅供个人自动化学习与技术研究。使用前请阅读文末「免责声明」。**

## 功能特性

- ✅ **多账号签到**：每个账号独立凭证（token 备份），串行轮换 + 随机间隔 + 账号固定 UA，低调执行
- ✅ **当日去重**：当天已签到/已领取的账号自动跳过，绝不重复请求
- ✅ **猫猫旅行**：自动派出 / 到点（含随机延迟）收取奖励 / 自动重新派出；支持"仅收取""仅派出"
- ✅ **积分统计**：实时查询账号剩余积分，记录与上次的增量
- ✅ **凭证预检**：JWT 解析 token 有效期，过期/临期提前提示
- ✅ **退出码体系**：0=成功 / 1=业务失败 / 2=凭证失效，便于脚本与定时任务集成
- ✅ **Web 可视化界面**：账号管理、一键签到、一键全自动、旅行/收取、积分实时查看
- ✅ **定时任务**：Windows / macOS / Linux 一键注册每日执行

## 快速开始

```bash
# 0. 准备：在 WorkBuddy 客户端登录目标账号（客户端会生成登录态文件）

# 1. 添加账号（自动读取客户端当前登录凭证，每个账号执行一次）
python add_account.py                # 交互输入账号名（默认 account2...）
python add_account.py my_account     # 或直接指定账号名

# 2. 一键全自动（随机延迟 → 签到 → 旅行收取/派出）
python main.py --data-dir .data auto

# 3. 注册每日定时任务（签到：凌晨随机错峰）
python main.py --data-dir .data install-schedule --time 00:30 --random-delay 30

# 4. 查看状态与积分
python main.py --data-dir .data status
```

多账号：重复「客户端登录 → add-account」即可，各账号 token 独立备份，互不影响。

### Web 可视化界面

```bash
python webui.py --data-dir .data --port 8080
# 浏览器打开 http://127.0.0.1:8080
```

## 免 Python 一键版（Windows exe）

不想装 Python？项目提供打包入口 `launcher.py`，双击 exe 即自动启动 Web 服务并打开浏览器：

```bash
# 自己打包（约 9MB，纯标准库，无需额外依赖）
pip install pyinstaller
pyinstaller --onefile --name wb-checkin \
    --add-data "webui/index.html;webui" \
    --exclude-module playwright \
    launcher.py
# 产物：dist/wb-checkin.exe，双击即用
```

数据目录 = **exe 同级目录下的 `.data`**（整目录可随身携带/迁移；`--data-dir` 可覆盖）。请从 [GitHub Releases](../../releases) 或官方渠道获取预编译 exe，不要运行来路不明的文件。

## 命令一览

| 命令 | 说明 |
|---|---|
| `add-account <名称>` | 添加账号（自动读取客户端凭证） |
| `remove-account <名称>` | 删除账号（含凭证备份） |
| `list-accounts` | 列出账号及凭证状态 |
| `checkin [--account 名称]` | 执行签到 + 领礼包 |
| `cat-travel [--mode full/claim/depart]` | 猫猫旅行：完整 / 仅收取 / 仅派出 |
| `auto [--delay-max-minutes N]` | 一键全自动（随机延迟 + 签到 + 旅行） |
| `install-schedule` / `uninstall-schedule` | 注册 / 卸载定时任务 |
| `status` / `logs [--history]` | 状态查看 / 日志与历史 |

全局可选参数：`--data-dir 目录`（数据目录，默认 `~/.wb_checkin`）。

### 退出码（checkin / cat-travel / auto）

| 退出码 | 含义 |
|---|---|
| 0 | 全部成功 / 已领取 / 当日跳过 |
| 1 | 有账号业务失败 |
| 2 | 存在凭证失效（需重新登录客户端后刷新） |

## 接口说明

本项目调用的是 WorkBuddy 账号体系下的既有服务接口，用于完成签到、积分查询、成长任务等常规操作。接口的具体域名、路径与参数请**结合客户端自身行为自行研究**，本项目不提供任何接口探测 / 逆向 / 抓包教程。

## 设计原则：克制优先

与部分同类项目相比，本项目刻意保持克制，这是**有意为之的设计选择**，而非功能缺失：

- **不逆向客户端二进制**：接口信息通过客户端行为观察获得，不做 `app.asar` 解包等逆向操作
- **不提供接口探测教学**：README 与代码注释不教人如何发现/抓取接口
- **不设计风控对抗**：没有验证码识别、滑块绕过、请求伪装等功能；唯一的"随机化"只是接近真实用户的操作节奏（随机错峰、随机间隔、账号固定 UA）
- **仅作用于自身账号**：所有操作只针对本机备份的自己账号凭证，不涉及任何他人账号或数据
- **如实记录**：成功就是成功、失败就是失败，绝不编造结果

**这套克制的收益**：行为更接近正常用户 → 触发风控的概率更低 → **对想长期稳定使用的用户更友好**。与其追求"一次多拿"，我们选择"细水长流"。

## 数据目录与安全

- 凭证备份在 `<data-dir>/tokens/*.info`（权限 600），**请勿分享认证文件**
- `<data-dir>` 含账号登录态与 token，已被 `.gitignore` 排除，严禁提交到版本控制
- 每个账号的 accessToken 有效期约 60 天，过期后在客户端重新登录并重新 `add-account` 刷新
